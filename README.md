# 跨境账证侦探

面向跨境电商多站点经营数据的本地优先核验工具：把销售、广告、头程、采购、FBA 与利润归入统一口径，由确定性程序复算，发现差额后下钻到来源文件、工作表、数据行或 PDF 页面。

- 在线演示：https://hwccxx.github.io/cross-border-ledger-audit/
- 演示视频：https://hwccxx.github.io/cross-border-ledger-audit/video.html
- 项目源码：https://github.com/HWCCXX/cross-border-ledger-audit

## 隐私与数据声明

- 内置基准和测试数据全部为程序生成的合成数据，不代表真实企业。
- 导入文件只在当前浏览器内存中解析，不会上传服务器；刷新页面后导入内容即被清除。
- 公开站点包不含用户导入的 ZIP、CSV、XLSX、JSON 或 PDF，也不含原始票号、税号、地址和银行账号。
- 模拟异常会显著标注为 `SIMULATION`，并在内存副本上运行，不修改用户原文件。

## 当前能力（技术环 0—12）

- **环 0：项目壳**——完成品牌、导航、合成数据声明和响应式静态站框架。
- **环 1：公开演示数据**——构建匿名合成经营基准，公开目录不含身份字段或原始票据。
- **环 2：统一数据模型**——统一月份、金额、费用类别和证据类型，并过滤重复入账的总计行。
- **环 3：确定性计算**——独立复算销售收入、成本结构、站点收入、利润和利润率。
- **环 4：基础核验**——通过 8 条勾稽规则核对月度、站点、结构、比例和费用来源。
- **环 5：核心界面**——完成经营总览、成本结构、核验结果和匿名证据弹窗。
- **环 6：文件导入**——支持 ZIP、CSV、TSV、JSON、XLSX、PDF 本地内存解析，自动识别 6 类结构化台账。
- **环 7：异常规则**——建立 11 条异常规则，覆盖月份、金额、月度闭合、站点销售、费用来源、广告期间和证据索引。
- **环 8：证据下钻**——支持定位来源文件、工作表、数据行和 PDF 页面，PDF 正文按需读取。
- **环 9：安全模拟**——支持广告差额、重复月份、期间错配和组合异常模拟，仅修改内存副本，可一键还原。
- **环 10：确定性解释**——通过固定模板输出可能原因、影响、建议动作和计算口径，不让生成式模型直接计算金额。
- **环 11：集成测试**——完成 Node 单元回归及真实浏览器端到端回归，验证桌面端、移动端、文件导入、PDF 读取和模拟还原。
- **环 12：部署与比赛材料**——完成公开 GitHub 仓库、GitHub Pages 在线演示、封面、海报、演示视频、源码包和制作日志。

## 运行

推荐从项目根目录启动本地静态服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

然后访问 `http://127.0.0.1:8765/`。直接双击 `dist/index.html` 也可使用总览和结构化文件导入，但部分浏览器会阻止 `file://` 页面动态加载 PDF 解析模块。

在“导入与异常”页拖入数据包或选择多个文件。支持 `.zip`、`.csv`、`.tsv`、`.json`、`.xlsx`、`.pdf`；单文件上限 30 MB，ZIP 最多解析 500 个受支持条目。

## 合成样例实测结论

对 `示例店铺C-2026年1-9月经营数据.zip` 的端到端回归结果：

- 成功识别 173 个受支持文件、11 张结构化表和 165 份 PDF。
- 9 个月销售收入合计 16,000,000 元，基础经营结构闭合。
- 检出 1 条应复核口径：月度采购成本为含税价 3,200,000 元，采购台账不含税金额为 2,831,858.39 元，差额 368,141.61 元等于进项税额。

## 验证

确定性单元回归：

```powershell
node tests/run-tests.js
```

预期为 `16/16 tests passed`。浏览器回归脚本还会验证响应式布局、文件导入、模拟还原、PDF 读取以及上述采购含税/不含税差额。

## 当前边界

- 当前自动字段识别针对本项目首批样例表头；其他企业格式可能需要扩充别名或可视化字段映射。
- 本工具提供经营核验与证据索引，不替代会计审计、税务申报或法律意见。
